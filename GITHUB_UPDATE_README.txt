HOW TO UPDATE GITHUB:
1. Open your GitHub repository.
2. Click "Add file" -> "Upload files".
3. Open this ZIP on your computer and select ALL files/folders inside it.
4. Drag them into the GitHub upload area.
5. If GitHub asks about replacing existing files, choose to replace/overwrite them.
6. Scroll down to "Commit changes".
7. Use a message such as: "Update 5-year goals and founder section".
8. Click "Commit changes".
9. Wait 1–3 minutes for GitHub Pages to rebuild.
10. Open your website and hard-refresh the page (Ctrl+F5 on Windows).

IMPORTANT:
- Upload the contents of this package into the SAME repository/root location as your existing site.
- Do not upload the ZIP file itself as the website.
- Keep index.html in the repository root if it was there before.
